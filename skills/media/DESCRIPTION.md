# Media

One skill, vendored from the Hermes library: `youtube-content`.

The aquarium hobby's advice is mostly video, mostly undated, and mostly written
for someone else's tank. A transcript makes a specific claim quotable, which is
the first step to judging it against `aqua status` rather than against
impressions.
